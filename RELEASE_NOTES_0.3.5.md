# Violet CMS 0.3.5

Fase centrada en producto visual: sticky add to cart mas premium y galeria de producto mas cuidada.

## Producto

- Sticky ATC muestra imagen, titulo, variante, precio y estado.
- La imagen del sticky cambia cuando la variante tiene media propia.
- El precio, variante y estado se actualizan al cambiar variante.
- `variantStrings` incluye `inStock` para mantener traduccion correcta.

## Galeria

- Anadido `violet-product-media-plus.css`.
- Activado `thumbnail_slider` como layout de producto por defecto.
- Activadas miniaturas visibles en movil.
- Pulidos bordes, estado activo, hover de imagen y botones de galeria.

## Validacion

- Theme Check limpio.
- JS validado con `node --check`.
- JSON de producto validado.
